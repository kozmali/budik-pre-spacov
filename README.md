## 🛡️ Hlavné funkcie / Key Features (SK / EN)

* **Rozdelenie obrazovky 73 % / 27 %:** Veľké tlačidlo *Odložiť* (73 %) a menšie tlačidlo *Zrušiť* (27 %) zabraňujú náhodnému vypnutiu budíka v polospánku. / *Large Snooze area (73%) and smaller Dismiss area (27%) prevent accidental dismissal while half-asleep.*
* **Poistka času (Time Failsafe):** Posledný hraničný čas, kedy už naozaj musíš vstať. Po jeho prekročení sa spustí núdzové pípanie a 5 línií záchrany. / *The ultimate wake-up limit that triggers an emergency beep and 5 rescue lines.*
* **5 línií záchrany (5 Rescue Lines):**
  1. Falošné zrušenie (tiché odloženie o 1 minútu) / *Fake dismiss (1-minute silent snooze)*
  2. Blikajúci dôvod vstávania + 45 s odpočet ticha s 10 s oknom na potvrdenie / *Flashing wake-up reason + 45s countdown*
  3. Uhýbajúce tlačidlo Zrušiť (chyť 3-krát) / *Dodging dismiss button (catch 3 times)*
  4. Podržanie tlačidla na 4 sekundy / *Hold button for 4 seconds*
  5. Kontrola bdelosti o 2 minúty (automaticky sa preskočí, ak senzor zaznamená pohyb s telefónom) / *Wake-up check after 2 minutes (skipped if motion is detected)*
* **Dynamická ikona OFF:** Keď je budík deaktivovaný, na ikone aplikácie na ploche svieti výrazný nápis `OFF`, aby si nikdy nezabudol budík zapnúť. / *Dynamic launcher icon displays an `OFF` badge whenever the alarm is deactivated.*
* **Zvuky budenia:** Systémový budík, syntetizované melódie, vlastné MP3 súbory, YouTube a Spotify skladby. / *Supports system alarm, synthesized melodies, local MP3s, YouTube, and Spotify tracks.*
